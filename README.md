# Eyad Gaber — Portfolio

Personal portfolio of **Eyad Gaber** — Full Stack & Systems Developer specializing in Linux environments, native desktop tooling, real-time web applications, and cross-platform development.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **3D Graphics**: [Three.js](https://threejs.org/) & React Three Fiber
- **UI & Components**: React, TypeScript
- **Styling**: Vanilla CSS Design System

## 🚀 Getting Started

```bash
# Install dependencies
bun install

# Start local development server
bun run dev

# Build for production
bun run build
```
